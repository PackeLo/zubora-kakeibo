# ズボラ家計簿プラグイン

リモートMCP接続と利用手順を含む開発用パッケージ。秘密やローカル実行コマンドは含まない。

このパッケージをZIPでインポートすると、MCP宣言があるため接続先がHTTPSでもDesktop onlyになる。スマホ向けの導入には使わない。[公式のインポート制限](https://learn.chatgpt.com/docs/enterprise/plugin-management#desktop-only-plugins)を参照する。

## 接続

MCP URL: `https://zubora-kakeibo.packagelockjson2525.workers.dev/mcp`

OAuthで接続し、家計簿に許可された自分のメールでログインする。APIキーを入力する方式ではない。
通常の接続は読み取り・下書き取り込み・資産変更の権限を要求する。分類変更は管理者のみ追加の`kakeibo:taxonomy:write`権限を許可できる。

スマホ向けには、ChatGPT Webの対応するカスタムMCP接続からURLとOAuthを登録する。項目がない場合はワークスペースの作成権限と機能提供状況を確認する。必要なら登録後のアプリIDを参照する方式で利用手順を添える。MCP宣言を同梱したZIPのアップロードやローカルmarketplaceへのインストールを、スマホ対応の代用にしない。

## 公開機能

- カテゴリ・タグ、家族のユーザー一覧。
- レシートなどの下書き登録。
- 家計の概要、月別・カテゴリ別集計、件数制限付き明細。
- カテゴリ・タグの登録・編集・削除/無効化（管理者のみ）。
- 金融資産の一覧・登録・編集・無効化。

明細の訂正と確定は管理画面で行う。接続・実データへのアクセス・スマホ利用・家族への共有をそれぞれテストしてから運用する。
