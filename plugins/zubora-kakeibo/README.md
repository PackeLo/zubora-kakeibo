# ズボラ家計簿プラグイン

リモートMCP接続と利用手順を含む開発用パッケージ。秘密やローカル実行コマンドは含まない。

このパッケージをZIPでインポートすると、MCP宣言があるため接続先がHTTPSでもDesktop onlyになる。スマホ向けの導入には使わない。[公式のインポート制限](https://learn.chatgpt.com/docs/enterprise/plugin-management#desktop-only-plugins)を参照する。

## 接続

MCP URL: `https://zubora-kakeibo.packagelockjson2525.workers.dev/mcp`

OAuthで接続し、家計簿に許可された自分のメールでログインする。APIキーを入力する方式ではない。
読み取り・下書き取り込み・下書き編集・確定・確定済み編集・資産変更を、それぞれの権限で許可する。分類変更は管理者のみ追加の`kakeibo:taxonomy:write`権限を許可できる。

スマホ向けにはSitesで公開する接続プラグインを使う。設定は[接続サーバーの説明](../../app/connection/README.md)を参照する。公開更新後は新しいチャットで対象を選び、追加ツールを確認する。MCP宣言を同梱したZIPのアップロードやローカルmarketplaceへのインストールを、スマホ対応の代用にしない。

## 公開機能

- カテゴリ・タグ、家族のユーザー一覧。
- レシートなどの下書き登録。
- 確認待ち明細の一覧・取得・編集と、条件を満たす95%超の明細の確定。
- 確定済み明細の取得・編集と、登録者・対象者による絞り込み。
- 家計の概要、月別・カテゴリ別集計、件数制限付き明細。
- カテゴリ・タグの登録・編集・削除/無効化（管理者のみ）。
- 金融資産の一覧・登録・編集・無効化。

管理画面にも明細の詳細・編集がある。低信頼度や不足のある確認待ちは画面で確認して確定する。接続・実データへのアクセス・スマホ利用・家族への共有をそれぞれテストしてから運用する。
